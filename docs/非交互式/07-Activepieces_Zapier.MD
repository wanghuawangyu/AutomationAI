# Activepieces、Zapier 与 Langflow 对比及 Zapier 免费政策

## 一、Activepieces：开源的业务自动化“连接器”

Activepieces 是一个**开源、可自托管的 AI 优先业务自动化平台**，常被视为 Zapier 的替代品。

- **核心定位**：连接你日常使用的各种 SaaS 应用和内部 API，实现业务流程自动化。它强调**治理和安全**，适合团队使用。
- **工作方式**：通过拖拽“触发器”和“动作”来构建名为“Flows”的自动化流程，与 Zapier 的体验类似。
- **关键特点**：
  - **开源可自托管**：采用 MIT 协议，你可以将数据和运行环境完全掌控在自己手中。
  - **AI 能力**：内置 AI 组件，支持连接本地 LLM，可构建 AI Agent，但 AI 深度不如 Langflow。
  - **扩展性**：使用 TypeScript 编写自定义组件，生态相对活跃，拥有 760+ 应用集成。
- **适合人群**：希望获得 Zapier 般易用性，但**重视数据隐私、需要自托管**的业务团队或开发者。

## 二、Zapier：云端自动化的“霸主”

Zapier 是市场领先的**云端 AI 编排平台**，以其庞大的集成生态和易用性著称。

- **核心定位**：连接超过 **9,000 个** 应用和服务，让非技术用户也能轻松实现跨应用的自动化。
- **工作方式**：通过创建名为“Zaps”的自动化工作流来连接不同应用，全程无需编码。
- **关键特点**：
  - **极致的易用性**：拥有最庞大的应用集成库和非常友好的用户体验。
  - **AI 增强**：正在向 AI 编排层演进，提供 AI 代理、聊天机器人等构建能力。
  - **闭源云服务**：作为商业 SaaS 服务，你无法自行托管，数据需要经过其服务器。
- **适合人群**：追求**开箱即用、集成最广泛**，且对数据存储在第三方云端没有顾虑的个人或企业用户。

## 三、Activepieces / Zapier 与 Langflow 是否是同类产品？

**Activepieces / Zapier 和 Langflow 不是同类产品。**

可以把它们想象成不同专业的工具：

- **Activepieces 和 Zapier 是“业务连接器”**：强项在于**连接**。它们像万能胶水，把各种现成的软件服务粘在一起，让数据自动流转。AI 是它们新增的一项能力，用于在流程中增加一些智能判断。
- **Langflow 是“AI 工作台”**：强项在于**构建**。它像一个精密的实验台，让你从零开始组装 AI 的“大脑”（LLM）、“记忆”（向量库）和“工具”，创造出全新的 AI 应用逻辑。

因此，如果你的目标是自动化日常办公流程，Activepieces 或 Zapier 是合适的选择。如果你的目标是构建和调试复杂的 AI 应用逻辑，那么 Langflow 才是更匹配的工具。

## 四、Zapier 是免费的吗？

Zapier **有免费计划，但功能限制非常严格**，更像一个“体验版”而非可长期依赖的自动化工具。

### ✅ 免费计划包含什么

- **价格**：$0/月，**永久免费**，无需信用卡
- **任务额度**：**100 个任务/月**（一个“任务”指一次成功的自动化动作）
- **Zap 数量**：**无限**，可创建任意多个工作流
- **步骤限制**：每个 Zap **只能有 2 个步骤**（1 个触发器 + 1 个动作）
- **核心套件**：可使用 Tables、Forms 的基础功能，以及 **Copilot**（AI 助手，有每日消息上限）
- **用户数**：**仅限 1 个用户**
- **轮询间隔**：**15 分钟**检查一次更新
- **试用**：新账户可获得 **14 天 Professional 计划试用**

### ❌ 免费计划缺少什么

- **多步骤 Zap**：无法在一个工作流中串联 3 个或更多动作，这是免费版最致命的限制
- **Premium 应用**：无法连接 Zapier 应用库中标记为“高级”的应用，**Webhooks 也属于高级应用**，免费版不可用
- **Filters、Paths、Formatter** 等高级流程控制工具
- **更快的轮询**：免费版固定 15 分钟，付费版可缩短至 1–2 分钟
- **AI 数据增强**：Zapier Tables 中的 AI 字段和数据增强功能不可用
- **邮件/在线客服支持**：免费版只能通过社区求助

### 📊 付费计划起步价

| 计划 | 价格（年付） | 任务/月 | 关键解锁 |
|:---|:---|:---|:---|
| **Free** | $0 | 100 | 基础体验，2 步 Zap |
| **Professional** | **$19.99/月** | 750 | 多步骤 Zap、Premium 应用、Webhooks、Filters/Paths |
| **Team** | $69/月 | 750+ | 共享权限、SAML SSO |

## 五、针对内网 Agent CLI 场景的结论

Zapier 的免费计划**不适合你的内网 Agent CLI 编排场景**：

1. **Webhooks 不可用**：免费版无法通过 Webhook 接收外部触发，而你需要的正是非交互式、由事件驱动的自动化。
2. **只有 2 个步骤**：你设想的“DeepSeek 写代码 → Codex 检查 → 不一致则重做”至少需要 3–4 个步骤，免费版根本无法表达这种流程。
3. **100 任务/月**：对于真实的 Agent 协作任务，额度极容易耗尽。
4. **闭源云服务**：即使付费，数据也必须经过 Zapier 的服务器，与你的内网权限校验要求根本冲突。

**结论**：Zapier 有免费计划，但它的免费版是一个**功能演示**，而非可用的自动化方案。对于你的场景，无论免费还是付费，Zapier 都不是合适的选择。Activepieces 虽然开源可自托管，但其定位仍是业务连接器，AI 深度不足，同样不适合作为你内部 Agent CLI 的核心编排工具。
